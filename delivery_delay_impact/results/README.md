# 📈 Results

This folder stores result CSV files used in portfolio narratives and dashboards.

## 📄 File List
- `results/priority_impact_top30.csv` - top 30 segments by `opportunity_score`
- `results/priority_risk_delay_top30.csv` - top 30 segments by `delayed_rate`
- `results/priority_risk_lift_top30.csv` - top 30 segments by `low_rating_lift`
- `results/state_pair_delay_top50.csv` - top state pairs by `delayed_rate` (customer_state x seller_state)
- `results/state_pair_volume_top50.csv` - top state pairs by `orders_cnt`

## 🧩 Common Columns
- `orders_cnt`: order count by segment/pair
- `delayed_rate`: delayed-order ratio (`delayed_flag = 1`)
- `low_rating_rate`: low-rating ratio (`review_score_avg <= 2`)
- `low_rating_lift`: low-rating gap between delayed vs on-time orders
- `opportunity_score`: `low_rating_lift * orders_cnt`

## 📝 Notes
- Segment outputs are generated by `sql/50_priority_scoring.sql` and `sql/51_priority_views.sql`.
- State-pair outputs are generated by `sql/41_state_pair_analysis.sql`; orders without reviews are excluded.
- Some CSV files may include carriage returns in `category_main`; trimming is recommended when needed.
